? Deployment instructionsIntune, Autopilot, GPO, SCCM, RMM, Linux & macOS
Intune / Autopilot

Upload the MSI as a required Windows app and assign it to the Autopilot device group. Install in system context before the Enrollment Status Page completes.

Active Directory GPO

Add the MSI under Computer Configuration → Software Installation, or run it from a computer startup script using msiexec /i WardenAgent.msi /qn.

SCCM / third-party RMM

Deploy the MSI silently in system context. Detection can use the Warden Agent Windows service. Re-running the MSI upgrades or reconnects the existing installation.

Linux / macOS Alpha

Extract the ZIP and run sudo ./install.sh. Linux registers a systemd service; macOS registers a launch daemon. Pilot on non-critical devices first. Grant Screen Recording and Accessibility through local settings or MDM for remote control.

Credential safety

Use a limited enrollment count where practical and revoke the installer after rollout. Each enrolled endpoint receives its own API key and client certificate.
