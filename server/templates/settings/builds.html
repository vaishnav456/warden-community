Emergency Agent Removal Script

Fully removes the WardenAgent Windows service and its data directory when it's stuck under its own tamper-protection lock (can't be started, stopped, or removed by an Administrator — net start/sc stop/sc delete all return Access Denied). This is not the normal way to remove a healthy agent — that's a server-approved UNINSTALL_AGENT job from an endpoint's detail page. Only use this when the agent isn't running well enough to receive that job — after running it, the machine has no agent at all and needs a fresh installer to reinstall. Every download is logged.
