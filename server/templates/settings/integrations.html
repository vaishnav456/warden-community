Required Microsoft setup

  1. Create an app registration in the customer's Microsoft Entra tenant.
  2. Create a client secret and copy its Value immediately. Do not paste the Secret ID.
  3. Under Microsoft Graph → Application permissions, add:
    Organization.Read.All
    DeviceManagementServiceConfig.Read.All
  4. Select Grant admin consent for the tenant.
  5. Confirm the tenant has an active Microsoft Intune licence.
No redirect URI is required. Warden uses Microsoft's server-to-server client-credentials flow. Access tokens are temporary and are not stored.
