Recovery checklist

  1. Keep a protected offline copy of the Home encryption key; Warden does not store that key.
  2. Configure a separate backup destination in the Home Node configuration. A separate disk on the same machine is not protection against losing that machine.
  3. Run and verify a backup. Verification decrypts files in memory and checks authenticated metadata without writing plaintext.
  4. Restore into a new, empty directory first. Recovery never overwrites the running Home store.
  5. Review the restored copy and node configuration before pointing the service at it.

These checks do not prove your offline key escrow exists. Encryption keys and file contents are never uploaded to this console.

Local node commands

warden-home backup --config warden-home.json

warden-home verify-backup --config warden-home.json --snapshot SNAPSHOT_ID

warden-home restore-backup --config warden-home.json --snapshot SNAPSHOT_ID --restore-root NEW_EMPTY_DIRECTORY

Run on the node with its protected configuration. The destination and recovery key must be supplied by the operator; this page never retrieves or rotates them.
