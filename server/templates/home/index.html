The normal Warden Agent stays on employee endpoints. Install the separate Warden Home Node on a Windows or Linux computer that will store the files. Create a node below; Warden then generates its configured ZIP or TAR.GZ with all required keys included.

Download, install, or upgrade — executable and JSON together
  1. For a new server, create the storage node below and download its one-time configured package.
  2. For an existing server, download the current executable below. Its upgrade command preserves the installed JSON, identity, keys, and encrypted data.
  3. Run the displayed command as Administrator/root. The service restarts automatically.
  4. Wait until the node status returns to Online, then retry synchronization.
Download Windows updateDownload Linux update
Windows (Administrator): .\warden-home-node-windows-amd64.exe upgrade
Linux (root): sudo ./warden-home-node-linux-amd64 upgrade
Future updates are automatic. After this release is installed, Warden Home reports its version and accepts only newer server-signed, SHA-256 verified binaries. Windows and Linux preserve configuration, identity, encryption keys, and data, with automatic rollback if the updated service cannot start.
Protect configured packages. New-node packages contain node and file-encryption keys. Delete the extracted setup copy after installation and keep a separate protected backup of the encryption key.
Which deployment mode should I use?
P2P VPN

Best for private nodes and roaming endpoints. Endpoint-to-node and primary-to-backup transfers connect directly when possible. If NAT or firewall rules prevent that path, Warden relays only the already encrypted mTLS byte stream over HTTPS.

Local network

For endpoints already on the office network or a organization VPN. Enter a stable private HTTPS address.

Public server

Use a public DNS address you control, strict firewall rules, monitoring, and regular backups.

Hybrid

Configure private and public HTTPS addresses for automatic address fallback.

Encrypted transport. P2P VPN tries ICE/STUN hole punching and automatic router mapping when supported. If direct traversal is unavailable, both peers connect outbound over HTTPS and Warden forwards their encrypted mTLS stream. No manual port forwarding is required.
Which domain and certificate can I use?

You can use any domain or subdomain your organization controls, such as home.example.com. Point its DNS record to the Home Node. A local-only node can use a stable private address such as https://192.168.10.20:9443.

Keep the registered address accurate. Warden derives the certificate’s DNS/IP names from the addresses below and ignores names requested by the node.

No certificate purchase or fingerprint is required. Warden issues a seven-day device certificate and the Home Node renews it automatically before expiry.

How spaces, folders, and permissions work

Where users see files
Personal home spaces synchronize to the selected profile folder such as Documents. Shared spaces appear inside the Warden Shares drive, using W: when available and then V: through R:. The synchronized cache remains available offline.

Multiple assignments
One endpoint can receive many spaces, and one space can target many endpoints through organization, branch, tag, endpoint, or identity scope.

Read-only or read-write
Read-only grants can download but cannot change server data. Read-write grants allow upload and deletion. The storage node verifies every signed grant.

Limits and conflicts
The node enforces total quota and maximum file size. Newest wins compares modification time; keep both preserves conflicts; server wins treats the node copy as authoritative.
