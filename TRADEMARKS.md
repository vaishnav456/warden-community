# Warden trademarks

The open-source licenses cover source code and documentation, not product identity.

You may truthfully state that software is based on Warden Community. You may not use the Warden name, logo, domain names, or visual identity in a way that suggests a modified build, hosted service, company, or commercial offering is official or endorsed by the Warden project.

Modified public distributions should use a distinct product name and logo and clearly identify their relationship to the upstream project. Descriptive use in documentation, compatibility statements, package metadata, and attribution is permitted when it is not misleading.

This is an initial project policy, not a registered-trademark claim or legal opinion.
