# Governance

Warden Community is currently maintained under a benevolent-maintainer model while the contributor community forms.

## Maintainers

Maintainers review changes, manage releases, coordinate vulnerability handling, and protect compatibility and security boundaries. The current maintainers are identified through the repository's GitHub team and protected-branch rules.

## Decisions

- Routine changes are accepted through reviewed pull requests.
- Protocol, schema, cryptography, licensing, or trust-boundary changes require a written design discussion.
- Security decisions may be handled privately until coordinated disclosure.
- Releases require passing CI, an updated changelog, artifact checksums, an SBOM, and maintainer approval.

As the project gains independent maintainers, this document should be expanded with nomination, voting, conflict-resolution, and succession rules.
